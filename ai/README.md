# Sign Language VR - AI Module

This directory contains the artificial intelligence components for the
VR sign-language learning project.

## Planned responsibilities

- Load hand-joint data captured from Unity and the VR headset
- Preprocess and normalise hand movement sequences
- Train sign-recognition models
- Evaluate model accuracy
- Export trained models to ONNX
- Return predictions and feedback to Unity

## Current status

Initial AI project structure created.

## Main folders

- data - Raw and processed training data
- src - Python source code
- trained_models - Trained models and exported model files
- notebooks - Experiments and exploration
- tests - Automated tests
- docs - Data formats and Unity integration documentation
